# Этап 3: чат — план реализации

**Goal:** комнаты «группа» и «ученик ↔ учитель», WebSocket с переподключением и догрузкой, стикеры, картинки, фильтр мата (словарь редактирует админ), удаление сообщений, непрочитанные.

**Architecture:** чистая логика — `app/profanity.py` (нормализация и замена, без HTTP) и `app/chat.py` (комнаты, права, сообщения, непрочитанные, лимит частоты). `app/chat_hub.py` — подключения WebSocket в памяти единственного процесса; у каждого подключения своя очередь и задача-писатель, публиковать можно из любого потока. Маршруты `app/routes/chat.py` тонкие. Экран переписки рисует `app/static/js/chat.js` по JSON из страницы и событиям WebSocket.

**Spec:** §5.4, §7 (ChatRoom, ChatMessage, ChatReadMark, BadWord, BadWordException, ReplacementWord), §8.5, §8.6, §9, §10.

## Global Constraints

- Всё из Global Constraints этапов 0–2 (без Node/CDN, русский UI, CSP без inline-скриптов, даты в БД — naive UTC, Origin-проверка, коммиты без упоминания Claude).
- Один процесс uvicorn: состояние чата (подключения, лимит частоты) — в памяти.
- Комнаты создаются лениво (get-or-create при открытии списка): одна на группу (`group_id` уникален), одна на ученика (`student_id` уникален). Ученик без группы чата не видит.
- Участники: группа — активные ученики группы + её учитель; личная — ученик + учитель его группы. Админ (надмножество учителя) видит и модерирует все комнаты.
- Текст ≤ 1000 символов; не чаще 1 сообщения в секунду и 20 в минуту на пользователя (текст, стикер, картинка вместе); картинка ≤ 15 МБ на входе, на выходе ≤ 1280px WebP.
- Исходный текст отфильтрованного сообщения видят только учитель комнаты и админ.
- Удалённое сообщение у всех заменяется на «Сообщение удалено»; файл картинки удаляется с диска.
- История — по 50; догрузка после обрыва — по id последнего полученного.
- Стикеры — Microsoft Fluent Emoji (Flat, MIT) в `app/static/stickers`, список — в коде.

## Review Focus

1. Ученик не может читать/писать/удалять в чужой комнате (WS, история, картинки, удаление) — 404/ошибка (Task 3, 5).
2. Ученик, исключённый из группы / отключённый / со сброшенным паролем, перестаёт получать и отправлять сообщения (Task 3, 4).
3. Фильтр: обходы (латиница-двойники, цифры, «х.у.й», «х у й», «бляяя») ловятся; обычные слова («рубля», «застрахуй», «хлеб») — нет (Task 2).
4. Обрыв связи: после переподключения клиент получает пропущенные сообщения ровно один раз и в порядке (Task 4, 6).
5. Картинки чата видны только участникам комнаты и только пока сообщение не удалено (Task 5).
